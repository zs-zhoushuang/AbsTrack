This repository contains the network implementation and dataset of the work: "Zhou S, Tian C, Hao W, et al. AbsTrack: Multi-person Absolute Localization and Trajectory Tracking Using Commodity Wi-Fi" submitted to IEEE Internet of Things Journal, 2026.

The network was built using Python and TensorFlow, which need Python>=3.8 and TensorFlow=1.13.

The code for the proposed Transformer-based multi-person trajectory tracking network is provided in the "code" folder.

The virtual training data is provided in the "training_data" folder and the test data is provided in the "test_data" folder.

One can use the virtual training data and the test data in each environment to train the network and test its performance. Note that, the training data and test data have already been normalized.
